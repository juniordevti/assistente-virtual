# 🤖 Aysla AI - WhatsApp Bot com IA Local

## Apresentação

Aysla AI é um bot inteligente para WhatsApp desenvolvido com Node.js, integrado com inteligência artificial local utilizando Ollama.

O projeto permite criar um assistente virtual capaz de responder mensagens automaticamente com inteligência, controle por comandos e suporte a múltiplos idiomas.

## Installation

**Node.js `v18+` é obrigatório**

```sh
npm install

ollama pull mistral

ollama run mistral

node example.js
```
---
## Exemplo:
```bash
client.on('message', async (msg) => {
    if (msg.body === '!ia oi') {
        msg.reply('Olá, me chamo Aysla 🤖');
    }
});
```
